## 📖 Обзор проекта

Проект представляет собой глубокое переосмысление культового симулятора [1in8b.life](https://1in8b.life/ru/). 

При каждом запуске игрок случайным образом рождается в одной из 172 стран мира с вероятностью, точно пропорциональной глобальной рождаемости или численности населения. Пользователь проживает жизнь своего персонажа — от младенчества через школу, юность, профессиональные и личные развилки, болезни, кризисы до естественного финала.

### Что кардинально улучшено по сравнению с оригиналом:
- **Мгновенный отклик (Zero-Lag Pacing)**: переход по годам занимает `< 16 мс` по клику на кнопку «+1 Год» вместо медленных серверных задержек оригинала.
- **Турбо-режим (Auto-Play)**: автоматический прогон жизни со скоростью `0.3 с / год` с интеллектуальной автопаузой при появлении интерактивных дилемм и критических событий.
- **Интерактивные развилки (101 Decision Card)**: осмысленные жизненные выборы с прозрачными бейджами последствий (`+15 🎓`, `-10 💰`, `⚠️ Риск`).
- **Сетка жизни 10х10 (Life Grid)**: визуальная матрица на 100 лет, наглядно отображающая пройденные этапы, пережитые кризисы и оставшиеся годы.
- **Спутники жизни (Companion Lives)**: параллельное отслеживание 4 ровесников, родившихся в ту же секунду в разных уголках Земли.
- **Мемориальный экран и экспорт сторис**: глубокая финальная статистика с глобальными процентилями и генерация вирусных карточек 9:16 (Story) и 1:1 (Post) на HTML5 Canvas для соцсетей.

## 🎨 Ключевые особенности и интерфейс

Интерфейс спроектирован специально для поколения зумеров (Gen Z) и поколения Альфа:
- **Нео-брутализм и кибер-поп**: глубокий тёмный холст `#0D0F17`, контрастные неоновые акценты (электрический циан `#00F0FF`, неоновый лайм `#00FF66`, ядовито-жёлтый `#FFE600`, маджента `#FF0055`).
- **Тактильная физика**: жирные контуры 2–3px, жесткие тени со сдвигом `shadow-[4px_4px_0px_#000]`, пружинные микро-анимации на Framer Motion.
- **Мобильная эргономика**: соблюдение правила зоны большого пальца (Thumb-Zone), все главные кнопки расположены в нижней части экрана (`fixed bottom-0`), высота `100dvh` предотвращает прыжки интерфейса на мобильных устройствах.
- **Строгая адаптивность**: гарантированное отсутствие горизонтального скролла (`scrollWidth <= clientWidth`) на экранах от сверхкомпактных смартфонов (375px) до 4K-мониторов.

## 📊 Демографические источники и математический аппарат

Симуляция работает на 100% клиентском коде без серверных зависимостей, используя компактный предкомпилированный демографический датасет (~130 КБ):

1. **База данных 172 стран мира**:
   - Ежегодное число рождений, общая численность населения.
   - Ожидаемая продолжительность жизни при рождении ($e_0$) по полу.
   - Коэффициент младенческой смертности ($q_0$) и детской смертности до 5 лет ($U5MR$).
   - ВВП по паритету покупательской способности (GDP PPP per capita).
   - Индекс Джини (неравенство доходов) и доля расходов на здравоохранение из кармана граждан (Out-of-Pocket %).
   - Индексы урбанизации, конфликтности и уровень материнской смертности.
2. **Калибровка смертности Гомпертца-Мейкема (Gompertz-Makeham)**:
   - Встроенный численный 50-шаговый метод бисекции рассчитывает коэффициенты возрастной смертности $q_x$ от 0 до 110 лет так, чтобы интегральная продолжительность жизни точно сходилась с данными ООН ($\Delta \le 0.01$ года).
   - В возрасте 110 лет смертность достигает $q_{110} = 1.0$, абсолютно исключая бесконечную жизнь.
3. **Логнормальная модель доходов по индексу Джини**:
   - Распределение доходов домохозяйств строится через обратную функцию ошибки (erfcinv), определяя перцентиль благосостояния каждого персонажа в мировом масштабе (среди 8 миллиардов человек).
4. **Матрица 33 причин смерти ВОЗ**:
   - Распределение причин смерти учитывает 7 глобальных регионов, 7 возрастных когорт и индивидуальные множители риска образа жизни (курение повышает вес ХОБЛ и рака легких в 2.5 раза).

**Авторитетные источники данных:**
- *United Nations, Department of Economic and Social Affairs, Population Division (2024). World Population Prospects 2024.*
- *World Health Organization (2021). Global Health Estimates: Leading causes of death and disability-adjusted life years.*
- *The World Bank Group (2023). World Development Indicators & Poverty and Inequality Platform.*

## 🔊 Процедурный Web Audio и голосовая озвучка (Web Speech)

В проекте реализована продвинутая двухуровневая аудио-подсистема, не требующая загрузки внешних аудиофайлов (`zero-asset audio`):

1. **Процедурный синтезатор Web Audio API (`SoundEngine`)**:
   - **Тактильный клик (`click`)**: ультра-короткий частотный импульс (800 Гц → 200 Гц за 30 мс) для приятного отклика на кнопки.
   - **Ход года (`step`)**: мягкий свист прогресса с синусоидальной огибающей.
   - **Пульс жизни (`heartbeat`)**: низкочастотный саб-басовый удар (55 Гц).
   - **Достижения и вехи (`milestone`)**: мажорное арпеджио на волне типа треугольник (C5 → E5 → G5 → C6).
   - **Кризисы и болезни (`crisis`)**: диссонирующий спадающий пилообразный тон.
   - **Похоронный колокол (`death`)**: гармонический составной аккорд (A2, E3, C4) с долгим экспоненциальным затуханием (3.5 секунды).
2. **Голосовая русскоязычная озвучка (Web Speech API)**:
   - Интегрированный синтез речи `window.speechSynthesis` с русским акцентом (`ru-RU`).
   - Дикторское озвучивание ключевых моментов: момента рождения и страны, достижения совершеннолетия (18 лет), судьбоносных решений и финальной эпитафии.
3. **Независимое управление звуком**:
   - В шапке интерфейса размещены независимые тумблеры: **Звуковые эффекты (SFX)** и **Голос диктора (Voice)**.
   - Состояния мгновенно синхронизируются с `localStorage`.

## 🚀 Быстрый старт (1-Click Launch)

Для запуска требуется только [Node.js](https://nodejs.org/) (версия 18 или новее).

### Вариант 1. Запуск в один клик на Windows (Рекомендуется)
Дважды щелкните по файлу:
```
start.bat
```
*Скрипт автоматически проверит Node.js, при необходимости соберет проект, запустит локальный production-сервер и откроет симулятор в вашем браузере по адресу `http://localhost:4173`.*

Также доступен альтернативный командный файл:
```cmd
preview.cmd
```

### Вариант 2. Запуск на macOS / Linux / WSL
Выполните в терминале:
```bash
chmod +x start.sh
./start.sh
```

### Вариант 3. Запуск через npm
```powershell
# Установка зависимостей (при первом клонировании)
npm.cmd install

# Запуск локального сервера разработки
npm.cmd run dev

# Сборка production-версии и запуск preview-сервера
npm.cmd run build
npm.cmd run preview
```

После запуска симулятор доступен по адресу:  
👉 **http://localhost:4173** (preview) или **http://localhost:5173** (dev)

## 🧪 Команды тестирования и верификации

В проекте развернута строгая 4-уровневая система автоматизированного тестирования.

### 1. Модульные и математические стресс-тесты (Vitest)
```powershell
npm.cmd test
```
*Запускает 15 тестовых наборов (176 тестов):*
- Сходимость численного метода бисекции Гомпертца-Мейкема для всех 172 стран.
- Логнормальное распределение доходов и квантование по Джини.
- Стресс-прогон 101 карточки решений на 10 разных сидах PRNG.
- 100 полных циклов жизни в режиме стресса без единого сбоя.
- Проверка чистоты редьюсеров, отсутствия `NaN` и зажима характеристик [0, 100].

### 2. Сквозные проверки в реальном браузере (Playwright Headless Runner)
```powershell
node scripts/verify-browser.js
```
*Проверяет:*
- 4 ключевых вьюпорта:
  - `mobile-se` (375 × 667, ультра-компактный смартфон)
  - `mobile-modern` (390 × 844, современный смартфон)
  - `desktop-standard` (1440 × 900, ноутбук)
  - `desktop-fhd` (1920 × 1080, Full HD монитор)
- Инвариант нулевого горизонтального скролла (`scrollWidth <= clientWidth`).
- Модальное окно 18+ и сохранение согласия в `localStorage`.
- Безопасный режим (12+).
- Быстрый стресс-клик тумблеров звука (20 кликов в секунду).
- Экспорт карточки на HTML5 Canvas 2D.
- **Строгий перехватчик**: падение теста при наличии хотя бы одной ошибки в консоли браузера (`console.error`).

### 3. Полный прогон всех тестов
```powershell
npm.cmd run test:all
```
